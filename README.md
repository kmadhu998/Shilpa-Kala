# Shilpa Kala

Shilpa Kala is an Android application that connects local artisans with users, enabling them to showcase, promote, and sell traditional sculptures, handicrafts, and artwork digitally.

The platform helps preserve cultural heritage while providing artisans with better visibility and direct customer interaction.

---

## Features

- User & Artisan Authentication
- Artwork Upload and Management
- Product Showcase with Images
- Add to Cart Functionality
- WhatsApp Chat Integration
- Heritage Information Section
- Firebase Database Integration
- Real-time Product Updates

---

## Tech Stack

- Kotlin
- Jetpack Compose
- Android Studio
- Firebase Authentication
- Firebase Realtime Database
- Firebase Storage

---

## Project Modules

### User Module
- Browse artworks
- View artisan products
- Add products to cart
- Contact artisans through WhatsApp

### Artisan Module
- Upload artwork images
- Add product details
- Manage product listings
- View customer interactions

---

## Purpose of the Project

The main objective of Shilpa Kala is to digitally empower traditional artisans by providing an online marketplace for showcasing cultural artwork and handmade products.
